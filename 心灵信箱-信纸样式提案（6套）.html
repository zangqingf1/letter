通用性实现说明（对应小程序 WXSS 迁移）：
1. 六套版式的装饰色一律由主题 palette 四色做透明度派生生成，切换主题只换 4 个变量，装饰逻辑零改动；小程序端可将 color-mix 预计算为 rgba 写入主题归一化结果（theme 服务已统一收口 palette）。
2. 固定锚点色仅两处：陶土 #C58A6A（信纸头线，与写信第一步 headline 同源）、鼠尾草/风化木（选中态与胶带）。
3. 全部为纯 CSS + 内联 SVG（postmark / 枝叶 / 角饰），无任何位图素材，符合方案B「信纸 = 配色 + 排版」，不增加包体。
4. 正文规格保持 16px(32rpx) · 行高 1.8，与详情 / 预览 / 分享导出一致；横格线 28.8px 与设计规范踩线对齐规则相同。
