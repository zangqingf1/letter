写下这封信 · 三版方案

针对「写信第一步」整页显示的三版重设计。三版梯度渐进，均沿用现有设计体系—— 暖纸米黄 + 鼠尾草绿 + 暖沙金、宋体标题 / 楷体手写、纸感邮路隐喻——不引入新隐喻，只换编排。
三版均完整保留页面功能：信名（20 字内）· 问题（500 字）· 答案（2000 字）三段必填与右下角实时计数 · 折痕分区 · 「没写完的信」草稿陈列（载入续写 / 撕毁）· 底栏「💾 存草稿 + 选主题」双按钮 · 顶栏「‹ 返回 + 写内容 · 选主题」步骤条 · 退出保护与编辑态差异不在提案内重复呈现。
机模内的页面可上下滚动，查看整页落位。
NO. 01

素笺正席 稳 · 现有整页信纸的精修升华

  • 保留「一页一张信纸 + 折痕分区」的现有骨架，落地成本最低。
  • 信头升级为完整仪式：陶土色顶线 + 居中宋体信名 + 日期行，右上角压一枚虚线圆小邮戳（与 detail 邮戳墙同语言）。
  • 字段引导语改为「其一 / 其二」编号式小字，鼠尾草绿编号 + 两侧短横线，更有书卷气。
  • 草稿陈列由虚线框升级为「便签夹」：鼠尾草虚线托盘 + 白卡带回形针角标、日期与「撕毁」线，呼应回形针页。
  • 底栏不变，主按钮保持火漆胶囊意象；细节放大见下方三张。

NO. 02

案头分笺 中 · 桌面上叠放的两张笺

  • 整页纸拆开摊在「桌面」上：页面底色改暖灰桌面（E9E8E1），信纸不再连成一整张，空间层级更清晰。
  • 信名做成「信封抬头标签笺」：小注「给这封信」+ 宋体信名 + 陶土色下划线，右上角一枚虚线小印。
  • 问题、答案分作两张独立纸笺上下叠放，答案笺左上压一枚金色回形针（呼应 clips 页），各带编号标签与计数。
  • 草稿陈列改为 detail 回信便签语言：米黄便签 ±1° 微倾、顶部胶带，两枚并排。
  • 折痕消失，改为两笺之间的自然间隙；底栏仍为火漆胶囊双按钮。

NO. 03

暖印编辑部 进 · 同色系内的精装刊物内页

  • 整个页面变成一张「信稿内页」：米黄纸通铺（F7F1E1），顶部一条鼠尾草装订带（含装订孔与页码感小字「第一页 · PAGE 01」）。
  • 宋体大刊头「写下这封信」+ 报头式粗细双线 + mono 日期栏，与「号外头版」信纸同血统但更克制。
  • 问题 / 答案用页边距「Q / A」方章标注（Q 空心墨色、A 实心鼠尾草），引导语退为栏上小字。
  • 计数改为页脚编目行：细线之上 mono「已书 53 / 上限 500」，编辑感十足。
  • 草稿陈列做成「待续稿 · 目录」：mono 日期 + 宋体稿名 + 点线引导 + 「撕毁」，像刊物的目录页。
  • 底栏主按钮由胶囊改方角 6px，墨色细顶线收边；仍是鼠尾草主色，不改色板。
